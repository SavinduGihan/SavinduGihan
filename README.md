## ⚔️ Featured Project — BattleBit

### 🤖 Dual-Robot Manual Combat System

**BattleBit** is a university robotics project combining embedded systems, electronics, wireless communication, and mechanical design.

The system features two independently controlled robots, each paired with a dedicated ESP32-based remote controller.

### 🤖 Robot System

- 🛞 Four-wheel mecanum drive for omnidirectional movement
- 🧲 Electromagnet for gripping and holding
- ⚙️ MG995 servo mechanism for lifting, pushing, and throwing
- 📐 MPU6050 sensor for body-orientation monitoring
- 🎯 Magnetic reed switches for hit detection
- ❤️ Real-time health monitoring
- 🔴 `DEAD` state when health reaches zero

### 🎮 Remote Controller

- 🕹️ Joystick-based movement controls
- ⚔️ Dedicated combat controls
- 🖥️ OLED display for real-time system information
- ❤️ Robot health and status monitoring
- 🔋 Battery-status monitoring
- 📡 Wireless communication-status monitoring
- 🔄 Two-way ESP32 communication
- 🛡️ Communication-loss fail-safe

### 🔩 Main Hardware

`ESP32` · `Mecanum Wheels` · `TT DC Motors` · `L298N` · `MG995 Servo` · `Electromagnet` · `MPU6050` · `Magnetic Reed Switches` · `OLED` · `18650 Battery Pack`

> 🚧 **Status: In Development**
