## ⚔️ Featured Project — Battle Bit

### 🤖 Dual-Robot Manual Combat System

**Battle Bit** is a university microcontroller-based project combining **robotics, embedded systems, electronics, wireless communication, and mechanical design**.

The system consists of **two independently controlled combat robots**, each paired with a dedicated **ESP32 remote controller**.

### 🤖 Robot System

* 🛞 Four-wheel **mecanum drive** for omnidirectional movement
* 🧲 **Electromagnet** for gripping and holding
* ⚙️ **MG995 servo mechanism** for lifting, pushing, and throwing
* 📐 **MPU6050** for body-angle monitoring
* 🎯 **Magnetic reed switches** for hit detection
* ❤️ Real-time health monitoring
* 🔴 **DEAD state** when health reaches zero

### 🎮 Remote Controller

* 🖥️ OLED display for real-time information
* ❤️ Health monitoring
* 🔋 Battery and system status
* 📡 Wireless communication status
* 🕹️ Joystick controls
* ⚔️ Combat controls
* 🔄 Two-way ESP32 communication
* 🛡️ Communication-loss fail-safe

### 🔩 Main Hardware

`ESP32` · `Mecanum Wheels` · `TT DC Motors` · `L298N` · `MG995 Servo` · `Electromagnet` · `MPU6050` · `Magnetic Reed Switches` · `OLED` · `18650 Battery Pack`

> 🚧 **Status: In Development**
