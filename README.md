## Featured Project: BattleBit

**BattleBit** is a university robotics project, a dual-robot manual combat system that combines embedded systems, electronics, wireless communication, and mechanical design. Two independently controlled robots each pair with a dedicated ESP32-based remote controller.

<table>
<tr>
<td valign="top" width="50%">

#### Robot

- Four-wheel mecanum drive for omnidirectional movement
- Electromagnet for gripping and holding
- MG995 servo mechanism for lifting, pushing, and throwing
- MPU6050 sensor for body-orientation monitoring
- Magnetic reed switches for hit detection
- Real-time health monitoring, with a `DEAD` state at zero health

</td>
<td valign="top" width="50%">

#### Remote Controller

- Joystick movement and dedicated combat controls
- OLED display showing robot health, battery, and link status
- Two-way ESP32 wireless communication
- Fail-safe on communication loss

</td>
</tr>
</table>

**Main hardware:** `ESP32` · `Mecanum Wheels` · `TT DC Motors` · `L298N` · `MG995 Servo` · `Electromagnet` · `MPU6050` · `Magnetic Reed Switches` · `OLED` · `18650 Battery Pack`

**Status:** In development. [View repository](https://github.com/SavinduGihan/BattleBit)
